¿Qué utensilios son esenciales para la preparación y conservación de grasas culinarias?

Para la preparación de la manteca de cerdo, se menciona el uso de un caldero para derretir las pellas y un tamiz fino para colarla. Para lograr una manteca blanca y espumosa, se utilizan varillas para batirla. En cuanto a la conservación, se especifica que la manteca se guarda en vasijas de barro. Para la limpieza de los recipientes de barro o cristal, se indica que deben lavarse con agua de sosa y jabón, enjuagarse abundantemente y escurrirse boca abajo hasta que estén completamente secos. Para la preparación de sebo, se utiliza una cacerola. Para las grasas de fritura, se menciona un tamiz muy espeso para filtrarlas.
